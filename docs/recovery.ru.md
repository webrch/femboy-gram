# Как исходники 1.0.31 вернулись из апк

Репозиторий на гитхабе пропал вместе с аккаунтом. Остались архив 0.99.17 у
постороннего человека и пререлиз 1.0.31 на телефоне владельца. Всё между
ними восстановлено из апк 1.0.31 (ноябрь 2026).

## Питон

Движок плагинов и слой совместимости с exteraGram лежат в апк байткодом
Python 3.11 (`assets/chaquopy/app.imy`). pycdc разбирает 3.11 плохо, поэтому
функции переписаны руками по дизассемблеру и докстрингам, которые байткод
хранит целиком. Проверка — `tools/recover/pyc_check.py`: каждый модуль
компилируется python3.11 ровно в байткод апк, функция за функцией. Номера
строк не сравниваются, поэтому комментарии внутри функций свои: в байткод
они не попадают.

## Джава

1. 0.99.17 собран на той же версии телеграма, что и 1.0.31 (12.10.1), без
   сборки C++: нативная библиотека взята готовой из апк.
2. Оба апк разобраны jadx, шум убран: номера ресурсов, имена лямбд R8,
   счётчики переименований jadx, подстановка строковых констант.
3. Разница сравнивалась по методам, а не по строкам: R8 переставляет методы.
4. Найденное перенесено в исходники 0.99.17 с комментариями, сборка
   повторена и сравнена с 1.0.31 ещё раз. Остался только шум декомпилятора
   в огромных методах и мелочи вроде порядка параметров лямбды.

`processUpdateArray` jadx не декомпилирует; его сверяли по сырым инструкциям
(`--comments-level debug`).

## Что появилось между 0.99.17 и 1.0.31

- свой прокси: MTProto-прокси на 127.0.0.1, который перекладывает соединение
  в WebSocket веб-версии (`FemboyProxy`, `FemboySocket`,
  `FemboyObfuscation`), предлагается сам, если связь висит и SIM российская;
- плагины exteraGram: `.plugin` переводится в `.marp` (`FemboyExtera`), рядом
  модули с их именами (`base_plugin`, `client_utils`, `ui/*` …);
- меню плагинов в четырёх местах: чат, профиль, сообщение, боковое меню;
- двери сети для плагинов: запросы, ответы и обновления (`on_request`,
  `on_answer`, `on_update`);
- свои пузыри в цветах своего градиента; профиль целиком в тон градиенту;
- можно спрятать вкладку «Все чаты»;
- стена сама дочитывает группу и открывается уже с найденным;
- заголовок «Message looks better with @femboyter» больше не прячется и не
  вырезается: его давно никто не пишет;
- премиум-значки переводятся в метки, только если своего премиума нет;
- версия показывается как «Пререлиз 1.0.N», а сравнивается как 0.99.N;
- китайский снова в сборке: телеграм 12.10.1 добавил фильтр языков без него.

Ключи API владельца в апк есть, в репозиторий они не попали и попадать не
должны.
